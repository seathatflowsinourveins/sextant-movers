# Landscape

One row per capability the ranking and the TradingView display need: the repository chosen for it, its pin, its licence, how it reaches its data, the runner-up and the evaluation receipt. The Package column names, relative to `src/sextant_movers/`, the packages and modules a row covers; `tests/repo/test_landscape.py` refuses a top-level package or module there that no row names, and holds every row to the states and pin rules below. A row's state is the first state name in its state cell.

The rule (Rule 1 in [AGENTS.md](../AGENTS.md), sharpened by [SOURCE-HIERARCHY.md](../SOURCE-HIERARCHY.md)): the official upstream comes first. A community repository is allowed where it is the best maintained practice, and it stays a candidate until this repository has run and evaluated it end to end. A tool that reaches TradingView by a reverse-engineered or terms-violating path is never used.

States:

- **adopted**: the chosen source; the work builds on it.
- **candidate**: named and pinned, not yet relied on. It becomes adopted, or rejected with the reason, after three things, each recorded with its commit: a clean install, an end-to-end run on recorded input, and the result written under `docs/research/`.
- **rejected**: not used, with the reason.
- **no source**: no repository or official surface was found; the row says why and what we do instead.

"Verified" names what was read for the row and when. "not verified" is a correct cell: it means nobody read the source yet, and nothing may rest on that cell. First version: 2026-11-11, from the lead's survey of that day, with every pin, licence and method name re-read from the repository or page named. Every tag and commit in the Capabilities and runner-up tables was re-measured with `git ls-remote` on 2026-11-11 (the peeled commit for an annotated tag); all matched. An adopted or candidate row with no 40-hex pin says "not pinned yet:" and why. TradingView's own pages were not read in this pass (a lead hold on all TradingView contact), so every TradingView terms or format cell says so.
